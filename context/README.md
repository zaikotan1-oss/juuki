# 重機で建てる 現状

## 2026-09-30 試作1（ショベルでビルを壊す＋iPad で性能を測る）
- 調べ物（サブエージェント5本）の結論で Web（Babylon.js＋Havok）に決めた。本人の iPad は iPadOS 26 以上 → WebGPU
- できている事
  - 一人称の運転席視点／外から視点の切り替え。画面ドラッグで見回し
  - 2本レバー（ISO: 左=旋回・アーム、右=ブーム・バケット）。走行は下の真ん中のペダル（◀・バック・アクセル・▶。押している間だけ、じわっと加速・減速）。画面の上の方をなぞると見回し
  - PC キー: A/D 旋回・W/S アーム・I/K ブーム・J/L バケット、走行は矢印
- ★2026-10-02 本人「まず前に進めない」→ 前は「作業/走行」ボタンで左レバーを切り替える方式で、切り替えに気づけなかった。切り替えをやめ、走行レバーを別に置いた（v6）。続けて本人「真ん中にアクセルとバックを置いて」→ ペダル式にした（v7）。モード切り替えで同じレバーの意味を変える作りは避ける
  - ビルは 1m 格子（3 階・約 255 格子・Havok の静的な箱）。バケット先端が触れた格子を消して破片 2 個に。地面につながらない格子は 1 個ずつ破片で落ちる（demolish の Voxel 方式を簡略化）
  - 重機の腕はキネマティック。当たりは ANIMATED の箱が見た目を追う（setTargetTransform）ので破片を押せる
  - 破片の上限 400（古い物から消す）。「破片+100」で重さを試せる。左上に fps・動いている破片の数・WebGPU/WebGL
- PC（WebGPU）の実測: 破片 400 個が落ちている最中で 1 コマ 2.8ms
- まだ: iPad 実機の数字、ダンプ・ブルドーザー・クレーン、目的とクリア、音（仮のエンジン音だけ）
